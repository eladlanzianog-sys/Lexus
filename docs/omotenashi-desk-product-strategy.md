# LEXUS OMOTENASHI DESK: מסמך אסטרטגיית מוצר למוקד השירות של לקסוס ישראל

> **השורה התחתונה:** המוקד לא סובל ממחסור באנשים טובים. הוא סובל ממידע מפוצל, מהתחייבויות שנופלות בין הכיסאות ומחוסר נראות בזמן אמת.
> המוצר המוצע, **Omotenashi Desk**, מאחד את כל אלה למקום עבודה אחד שמסונכרן בזמן אמת: תמונת לקוח מלאה, תיבה אחת לכל הערוצים, סטטוס רכב חי ומגדל פיקוד למנהלת.
> **יעדים ל-12 חודשים:** לקצר את זמן הטיפול הממוצע (AHT) ב-25%, להעלות את שיעור הפתרון בפנייה ראשונה (FCR) מ-~68% ל-80%+, ולהגיע ל-0 התחייבויות שחזרה אליהן לא בוצעה.

**השם:** *Omotenashi* היא פילוסופיית האירוח היפנית שלקסוס מזוהה איתה: לצפות את הצורך של האורח לפני שהוא מבקש. זה עקרון העיצוב המרכזי של המוצר.

**רכיבים ומיקרו-אינטראקציות**
- **כרטיסים:** רדיוס 14px, צל עדין מאוד (`0 1px 2px rgb(0 0 0 / .04), 0 8px 24px rgb(0 0 0 / .04)`) ו-glassmorphism עדין רק בשכבות צפות.
- **תנועה:** 200–280ms, ‏`cubic-bezier(.2,.8,.2,1)`. כניסה עם fade ו-translate של 8px. מונים מספריים "מתגלגלים".
- **טיימר התחייבות:** טבעת התקדמות דקה שמשנה צבע (אפור ← ענבר ← אדום).
- **שיחה נכנסת:** פס עליון שקט עם "נשימה" עדינה, בלי הבהוב.
- **נגישות:** WCAG 2.2 AA, יעדי מגע של 44px לפחות, תמיכה ב-`prefers-reduced-motion` ובמצב כהה (אופציונלי למשמרת לילה).

### 4.6 ניווט

- **דסקטופ:** סרגל צד צר בימין (72px, אייקונים עם tooltip) שנפתח ל-240px בריחוף. חיפוש גלובלי ב-⌘K / Ctrl+K.
- **מובייל:** Bottom tab bar עם 4–5 לשוניות בסדר RTL. בנציגה: בית, תיבה, חיפוש, משימות, אני. במנהלת: רצפה, התראות, צוות, עוד.
- **Responsive:** נקודות שבירה ב-390 / 768 / 1200 / 1440px. בטאבלט עמודת העזר נפתחת כמגירה.
